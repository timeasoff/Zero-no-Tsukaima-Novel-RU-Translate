# AINovelEdit — улучшение машинного RU-перевода новеллы

> **Инструкция для человека — [РУКОВОДСТВО.md](РУКОВОДСТВО.md) (от А до Я).**
> Этот README — техническое описание проекта.

Изолированная среда для агента: глава за главой превращает машинный
русский перевод японской новеллы в художественный текст, сверяясь с
японским оригиналом и английским переводом.

## Структура

````text

├── .agents/skills/              # системные инструкции для Cline
│   ├── novel-editor/            # роль и рабочий процесс

│   │                             #   AI-штампы → живой текст; references/ внутри

│   │                             #   залог и актанты (после редактуры)

└── dictionary.md                # канон терминов (каноническая идентичность;
                                  #   НЕ механическая строковая замена)

### Структура аудита

Аудит разделён на независимые слои. Каждый слой ищет свой класс
ошибок и не должен подменять следующий или предыдущий.

```text
translation-audit
↓
Смысл / соответствие JA и EN
↓
novel-editor
↓
Художественная редактура
↓
russian-humanizer
↓
Машинность / translationese / AI-штампы
↓
russian-prose-rules
↓
Оформление русской прозы
↓
russian-grammar-control
↓
Грамматика / управление / падежи / актанты / залог
↓
style_scan.py
↓
Механический поиск стилевых кандидатов
↓
russian-style-audit
↓
Тавтология / повторы / коллокации / избыточность / кальки
↓
FINAL AUDIT
↓
Проверка результата по всем слоям
````

## Подготовка данных (вне проекта)

Сырые файлы кладутся в `../origs/` как `<том>-ja.epub`, `<том>-en.pdf` и
RU-источник: `<том>-ru.docx` **или** `<том>-ru.md` (уже правленный перевод в
markdown — приоритет у docx, если лежат оба). Для RU-md: абзацы разделяются
пустой строкой, главы — заголовками `# Глава N: ...`; переносы строк внутри
абзаца склеиваются автоматически. Совпадение числа абзацев с оригиналом не
требуется — выравнивание DP разрезает склеенные и приклеивает лишние абзацы
к соседним. Если заголовков глав в md нет вовсе, абзацы распределяются по
главам EN пропорционально объёму (границы получаются приблизительными).

Затем из корня репозитория:

```bash
python tools/normalize.py --volume 14
```

Скрипт извлекает текст из всех трёх форматов, чистит его и выравнивает
абзацы трёх языков Открыть `AINovelEdit/` в Cline и дать задачу. Промпты для конкретных
томов, глав и режимов (первый запуск, продолжение, аудиты, обработка
блока) генерирует `tools/generate_agent_prompt.py` — он сам подставляет
все пути; вручную пути в промптах не меняются.

Правила работы агента (блоки, журнал решений, маркеры, порядок слоёв)
описаны в [AINovelEdit/AGENTS.md](AINovelEdit/AGENTS.md).
Пустые JA-строки в середине файла — место, где JA-абзац не нашёл пары.
