## Правило адаптации рунических инкантаций

Рунические инкантации не транслитерируются с катаканы. Порядок:
**японская запись → руническая этимология → историческая/авторская форма →
читаемая русская адаптация**. Примеры: オス → Os → Ос; ウリュ → Ur → Ур;
ラド → Rad → Рад; エオルー → Eoh → Эох; スーヌ → Sunu → Суну.
Элементы с неподтверждённой этимологией (フィル → Фир, ル → Ру) получают
нейтральную форму и пометку «требует проверки», не этиологизируются.
