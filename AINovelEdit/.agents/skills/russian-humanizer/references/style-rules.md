# Русская стилистическая традиция как проверяемые правила

> EN summary: Principles of the Russian editorial canon (Nora Gal, Chukovsky, Rosenthal, Milchin) restated as checkable "find → replace" rules, plus a machine-readable rule schema. Principles are paraphrased, not quoted.

Принципы переданы своими словами, без дословного цитирования книг.

## Правила (что искать → что делать)

1. **Глагол вместо отглагольного существительного** (Галь). Ищи: «-ение/-ание/-ация» в роли действия. Делай: верни глагол. «осуществление контроля» → «контролировать».

2. **Разбей нанизывание падежей** (Галь). Ищи: 3+ существительных в родительном подряд. Делай: глагол или дробление.

3. **Действительный залог по умолчанию** (Галь). Ищи: «было принято/сделано» без лица. Делай: верни лицо. Исключение: деятель неважен (наука, право).

4. **Канцелярит не на своём месте** (Чуковский). Ищи: официоз в неофициальном тексте. Делай: разговорно-нейтральное. В реальном документе — оставить.

5. **Не бойся простого слова** (Галь). Ищи: «сложное» слово при наличии простого и точного. «коммуницировать» → «говорить», если смысл цел.

6. **Тире вместо связки** (Галь). Ищи: «является/представляет собой» в настоящем времени. Делай: тире (с оговоркой жанра — `automation-policy.md`).

7. **Проверь управление и «Вы»** (Розенталь). Ищи: предлог+падеж по шаблону («согласно приказа»); прописное «Вы» в массовом тексте. Делай: исправь по норме.

8. **Конкретное вместо общего** (инфостиль + Галь). Ищи: эпитет, подходящий кому угодно. Делай: проверяемый факт — что, когда, с каким результатом.

9. **Русская типографика** (Мильчин). Ищи: прямые кавычки, Title Case, em-dash вплотную. Делай: «ёлочки», sentence case, тире с пробелами.

10. **Повтор лучше «синонимического бега»** (Галь). Не гони за синонимами: точное слово стоит повторить. Это ограничитель, а не правило-замена.

## Схема правила для машинной реализации

Каждое правило полезно хранить с условиями применения — чтобы инструмент объяснял, *почему* правит и *когда* не трогать:

```json
{
  "id": "nominalization_support_verb_001",
  "pattern": "осуществлять деятельность",
  "severity": "yellow",
  "evidence": "Галь",
  "default_rewrite": "работать",
  "mode": "suggest",
  "genres_apply": ["деловой", "публицистика", "лендинг", "письмо", "соцсети"],
  "genres_guard": ["договор", "нормативный акт", "научный"],
  "semantic_risk": "может быть юридическим термином",
  "positive_test": "Компания осуществляет деятельность в сфере обучения.",
  "expected_positive": "Компания работает в сфере обучения.",
  "negative_test": "Вид деятельности указан в лицензии.",
  "expected_negative": "leave_unchanged"
}
```

Поле `mode`: `auto` — зелёная зона (правим сами), `suggest` — жёлтая зона (предлагаем). См. `automation-policy.md`.
