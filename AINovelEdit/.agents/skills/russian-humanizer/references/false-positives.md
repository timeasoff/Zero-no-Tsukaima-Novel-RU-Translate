# Ложные срабатывания и границы

> EN summary: The anti-over-correction layer — the single most important part of the tool. Where a formal "AI marker" is actually correct or good Russian, and must be left alone. Over-correction produces a new cliché: unnatural uniform briskness.

Это самый важный файл проекта. Инструмент, который механически удаляет пассив, повторы, термины и списки, быстро начинает портить хороший русский — и сам рождает новый штамп: неестественную равномерную бойкость.

**Эмпирическая опора.** Детекторы ошибочно метят как ИИ формальный, нестандартный текст и тексты неносителей (Liang et al., 2023, *Patterns*; исследования 2024). Высокий «балл машинности» = стиль, под который детектор не обучен, а не доказательство генерации. Поэтому защита от переисправления — не сноска, а ядро.

## Где формальный признак — норма (не трогать)

| Признак | Когда норма | Как отличить штамп от приёма |
|---|---|---|
| Пассив | наука, право, инструкции, рецепты («образцы нагрели до 100 °C») | высокая плотность терминов → не трогать (порог по доменной лексике) |
| «является» | закон, определение, логика, математика | устанавливает точное отношение → оставить |
| Отглагольное сущ. | термин («оказание услуг», «распределение вероятностей») | часть устойчивого термина → оставить |
| Антитеза «не X, а Y» | реальный контраст и новая информация | удаляется ли вторая часть без потери смысла? да → балансир; нет → приём. Если X и Y — синонимы, это машина; если контраст («не сохранил, а вывел на IPO») — человек |
| Повтор слова | термин, утилитарное сущ. («пользователь», «кнопка») | синоним сменит понятие → повтор правильный |
| Триада | устойчивая / реальные 3 пункта / юр. перечень | смысл требовал двух или четырёх? → чини только принудительные |
| Тире | бессоюзие, пропуск связки, прямая речь, «Москва — столица» | правь избыток и англ. типографику, не класс |
| Список | инструкция, чеклист, шаги | 2–3 однотипные строки вместо прозы → проза |
| Таблица | сравнение по параметрам | есть данные для сопоставления → оставить |
| Markdown | README, GitHub, доки | среда рендерит → норма |
| Англицизм/термин | проф. среда (API, webhook, roadmap) | биграмма: «горный ландшафт» легален, «бизнес-ландшафт» — кандидат |
| Эмодзи | соцсети, мессенджер | часть выбранного голоса → оставить |
| Формальный регистр | договор, офиц. объявление | по природе суше → не «оживлять» |
| Дисклеймер | медицина, право, финансы | снижает риск вреда → оставить |
| «Вы» с большой | личное письмо одному адресату | адресат конкретен → оставить |
| Прямые кавычки | код, JSON, CLI | технический синтаксис → не трогать |

## Общий тест
Несёт ли элемент конкретную незаменимую информацию или делает реальную риторическую работу? Можно вычеркнуть без потери — штамп. Нельзя — приём, не трогай.

## Правило безопасности
Не править автоматически, если выполнено хотя бы одно:
1. текст юридический, научный, технический или нормативный;
2. замена меняет термин;
3. замена требует выдумать факт, цифру или субъекта;
4. конструкция повторяется как осознанный ритм, а не как штамп;
5. исходный текст уже естественен и понятен.

## Примеры: плохой и хороший пассив / повтор / антитеза

**Пассив.** «В ходе обработки заказа была допущена ошибка» (прячет ответственность в письме клиенту) → «Мы ошиблись при обработке заказа». НО: «Образцы поместили в раствор на 20 минут» (наука) → оставить.

**Повтор.** «Клиент отправляет заявку. Пользователь получает уведомление. Заказчик подтверждает данные» (машинное избегание повтора, три слова про одного) → «Клиент отправляет заявку, получает уведомление и подтверждает данные». НО: «Введите пароль. Пароль должен содержать восемь символов» → повтор термина оставить.

**Антитеза.** «Это не просто консультация, а пространство трансформации» (декоративная) → конкретизировать. НО: «Нам нужен не новый отчёт, а решение по убыткам» → оставить.
