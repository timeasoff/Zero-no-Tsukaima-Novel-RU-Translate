# Правила русской прозы (обязательны для редактуры и аудита)

Результат — markdown, но используются только: курсив `*…*`, blockquote `>…`
и заголовок главы. Жирный шрифт, подчёркивание и заголовки ниже первого
уровня не применяются.

## Прямая речь (диалог)

Каждая реплика — отдельный абзац, начинается с тире и пробела:

```
— Реплика целиком.
— Реплика, — сказал он. — Продолжение реплики.
«Цитата внутри реплики», — добавил он.
```

Правила:
* тире — длинное `—` (em dash), не дефис и не `–`;
* слова автора после реплики — со строчной буквы, перед ними запятая;
* если слова автора разрывают реплику, вторая часть — со строчной; если
  новое предложение — с заглавной: `— Первая часть, — сказал он. — Второе предложение.`
* реплика без слов автора — точка в конце, не `.—`;
* вопрос/восклицание перед словами автора: `— Что?! — воскликнул он.`;
* вложенная цитата внутри реплики — кавычки-«ёлочки».

## Абзацное оформление прямой речи

**Абзацная граница определяется не механической последовательностью
«реплика → авторский текст → реплика», а синтаксической и композиционной
функцией авторского текста.** Механическое правило «после авторского текста
прямая речь всегда начинается с нового абзаца» не применяется.

* Каждая самостоятельная реплика нового говорящего обычно начинается
  с нового абзаца:

  ```
  — Ты уверен?

  — Абсолютно.
  ```

* Авторские слова, синтаксически включённые в оформление той же реплики,
  абзац не разрывают:

  ```
  — Я думаю, — сказал командир, — что нам следует выступить немедленно.
  ```

  То же — если после авторских слов та же реплика продолжается:

  ```
  — Какое бы там ни было решение, — сказал командир, — проще всего бить
  их поодиночке, пока есть время. Идём!
  ```

* **Авторские слова после законченной реплики.** Если далее идёт
  самостоятельное авторское действие/повествование — отдельный
  композиционный шаг, его можно оформить новым абзацем:

  ```
  — Идём! — сказал командир полка.

  Он повернулся и направился к выходу.
  ```

  Если действие — непосредственное продолжение авторского сопровождения
  той же реплики, отдельный абзац не требуется:

  ```
  — Идём! — сказал командир полка и повернулся к выходу.
  ```

* **Авторская часть перед прямой речью — двоеточие обязательно.** Если
  абзац перед репликой — это **слова автора** (предложение, сказуемое
  которого — глагол речи: `сказал`, `проговорил`, `произнёс`,
  `воскликнул`, `спросил`, `ответил`, `прошептал`, `пробормотал`,
  `крикнул`, `отозвался`, `обратился`, `скомандовал`, `шепнул`,
  `бросил`, `добавил`, `продолжил`…), абзац **заканчивается двоеточием**,
  а реплика начинается с новой строки с тире:

  ```
  В конце концов Гиш проговорил вполголоса:
  — С ними эльфы.
  ```

  ```
  Юноши из отряда водных духов скисли. Маликорн тихо проговорил:
  — ……О-он уехал на родину.
  ```

  ```
  Твёрдым голосом сказал Гиш:
  — План? Да какой там план…
  ```

  Слова автора могут быть последним предложением абзаца (второй и третий
  примеры) — двоеточие всё равно ставится в конце абзаца, а не внутри.

* **Когда двоеточия нет.** Если абзац перед репликой — наррация, действие
  или описание без глагола речи в роли сказуемого, реплика начинается
  с новой строки, двоеточие не ставится:

  ```
  Собор на мгновение замер, а потом закипел, словно вода в котле.
  — Уоооооооооооооо!
  ```

  ```
  Жозеф кивнул и медленно поднялся с трона.
  — Тогда прошу сюда!
  ```

  Ключ — синтаксическая роль слова, а не его форма:
  * `сказал`, `проговорил`, `шепнул`, `отозвался`, `спросил` — сказуемое
    слов автора → двоеточие;
  * `кивнул`, `вздохнул`, `улыбнулся`, `усмехнулся`, `замер`, `поднялся`,
    `обратился против` — жест/действие → двоеточия нет;
  * глагол речи отрицается или входит в состав другого сказуемого
    (`Кастельмор не ответил на вопрос Жозефа, а наставил на него жезл.`) —
    это не слова автора → двоеточия нет;
  * `произнесла заклинание` — глагол речи в переносном (не речевом)
    значении → двоеточия нет.

* **Наррация и реплика в одной записи `ED_RU` — реплика с новой строки.**
  Если JA/EN держат наррацию и реплику вместе, результат сохраняет **одну
  запись** `ED_RU`, но реплика начинается с **новой строки внутри этой
  записи** (одиночный перенос строки; пустая строка создаст новую запись).
  Единица — смысловой блок: абзацную структуру внутри блока выбираешь сам.

  ```
  Но и молодой рыцарь был при исполнении.
  — Так пропустить я вас не могу: времена-то нынче какие…
  ```

  Слитная запись на одной строке **запрещена**:

  ```
  Но и молодой рыцарь был при исполнении. — Так пропустить я вас не могу…   ✗
  ```

  То же правило — для двух реплик разных говорящих, попавших в одну
  запись (EN/JA их не разбили): вторая реплика начинается с новой строки.

  ```
  — Ты навела заклятие на Луизу, да?
  — Н-нет, конечно.
  ```

  Контроль: `python scripts/check_records.py` (все главы) или
  `--file v14-chXX.md`; кандидат «. — Заглавная» разбирается по JA/EN —
  атрибуция после реплики, вводящие слова с двоеточием и продолжение
  реплики нарушением не являются, остальное исправляется через
  `fix_block.py` переносом строки перед тире.

* **Атрибуция после реплики — двоеточия нет.** Если абзац со словами
  автора стоит **после** реплики и поясняет её (реплика уже произнесена:
  предыдущий абзац — реплика с тире, говорящий назван в атрибуции либо
  есть отсылка «это» / «так»), атрибуция оформляется самостоятельным
  предложением **без двоеточия** (см. «Авторские слова отдельным абзацем
  после реплики»):

  ```
  — А если подождать, они рано или поздно сами выйдут к Луизе, нет?

  Сказал Гимли.

  — Нет… могут и обойти.
  ```

  ```
  — А кто такие варяги?

  Спросил Сайто.
  ```

  Практический тест — **кто говорит в следующей реплике?** Если это тот,
  кого называет атрибуция (его слова ещё не произнесены, атрибуция их
  вводит), — двоеточие ставится. Если следующая реплика принадлежит
  другому говорящему или атрибуция отсылает к уже сказанному — двоеточия
  нет:

  ```
  — Да говори же! Выкладывай!

  В конце концов Гиш проговорил вполголоса:
  — С ними эльфы.
  ```

  ```
  — А враги… ещё остались?

  Спросил Гиш.
  ```

  Отдельный пограничный случай — атрибуция между двумя репликами
  **одного** говорящего (`— Реплика. / Стиснув святыню, крикнула Луиза. /
  — Продолжение.`): атрибуция относится к предыдущей реплике, двоеточие
  не ставится; слияние в одну конструкцию запрещено alignment-инвариантом.
  При сомнении — пометка `???` и решение человека.

Такие случаи оцениваются по синтаксису, принадлежности авторских слов
к реплике и композиционной функции абзаца, а не по формальному наличию
знака: классификация абзаца — смысловое решение по JA/EN. Двоеточие
ставится только когда авторские слова **вводят** следующую реплику,
а не поясняют предыдущую.

### Техническое ограничение (не путать с alignment)

Перенос строки / абзацное оформление внутри `ED_RU` **не означает создание
нового alignment-абзаца**:

```text
один JA → один EN → один ED_RU
```

Если JA/EN представляют один исходный абзац, он остаётся **одной записью**
`ED_RU`, даже когда финальному русскому тексту нужен типографический
перенос. Внутри одной записи допустим **одиночный перенос строки**
(несколько визуальных строк); **пустая строка внутри `output/` создаёт новую
запись** и ломает инвариант — для визуального разрыва пустую строку
не использовать (см. скилл `save-progress`).

Правило касается только вида русского текста: `save_block.py`,
`fix_block.py`, `update_merged.py` и alignment-архитектура под него
не меняются. Предфильтры читают первую строку поля `ED_RU`, поэтому запись
с внутренним переносом проверяй глазами (RECHECK), а не только скриптом.

Правило двоеточия перед репликой действует и при переносе строки **внутри**
одной записи `ED_RU`: если слова автора и реплика разделены одиночным
переносом строки внутри записи, слова автора всё равно заканчиваются
двоеточием.

## Кавычки

* Основные — «ёлочки». Вложенные второго уровня — „лапки“.
* Названия книг, кораблей, песен в тексте автора — «ёлочки» + курсив не нужен.
* Никогда не оставляй прямые кавычки `"` из машинного перевода.

## Мысли и внутренняя речь

**Главное правило: внутренняя речь (то, что персонаж говорит сам с собой) —
ВСЕГДА курсив, без кавычек и тире.** Читатель должен сразу видеть, что персонаж
говорит сам с собой, а не вслух. Разметка в JA/EN не требуется и условием не
является — способ передачи определяется по смыслу.

* Внутренняя речь → курсив: восклицания, вопросы, решения, приказы себе,
  угрозы, мысленные обращения к другому, молитвы, счёт про себя, горькие или
  насмешливые реплики «про себя» — в т.ч. несобственно-прямая мысль, если по
  смыслу это голос персонажа: `*Больше нет сил терпеть. Час восстания настал…*`
* Авторское повествование (описание действий, чувств, обстановки в третьем
  лице) — обычный текст, даже если оно передаёт настроение персонажа.
* Если сомневаешься, вслух или про себя, — персонаж один или реагирует про
  себя → внутренняя речь (курсив); идёт обмен репликами с собеседником →
  вслух (тире).
* Слова автора при мысли — обычным шрифтом, как при реплике:
  `*Опять он за своё!* — подумала Луиза.`
* Абзацы внутри смыслового блока дели и объединяй свободно (границу блока
  не переносить). Если весь абзац — внутренняя речь, он
  целиком курсивом (включая каждую реплику «внутреннего голоса»); если мысль —
  лишь часть абзаца, курсивом только эта часть: `Он вздохнул. *Ну и денёк.*`
* Косвенная речь (пересказ: «он сказал, что...») — обычный текст, без тире,
  кавычек и курсива. Не переводи прямую речь в косвенную и наоборот —
  сохраняй способ передачи из JA (EN вспомогательный).
* Внутренний вопрос, восклицание или эмоциональная реакция **без авторской
  маркировки** («подумал», «пронеслось в голове») и без разметки в JA/EN
  остаются обычным текстом: сама по себе внутренняя природа вопроса курсива
  не требует. Курсив применяется, только когда абзац является внутренней
  речью как таковой (персонаж говорит сам с собой) либо мысль явно
  маркирована автором. Решения пользователя (19.09.2026): ch05 абз. 15 —
  авторская наррация; ch06 абз. 28 («Мятеж? Наступление?») и абз. 228–229
  («Вой?» / «Галлия начала войну?») — обычный текст, без курсива.

## Курсив и внутренняя речь — единственный допустимый синтаксис

Внутренняя речь (и весь курсив) оформляется **только** Markdown-курсивом
через звёздочки:

```markdown
*Я не могу поверить, что это происходит.*
```

* Форма `_текст_` **в проекте не используется и не считается допустимым
  вариантом** оформления курсива, несмотря на то что в общем Markdown
  подчёркивание формально допустимо.
* При обнаружении `_..._` в русском тексте заменить на `*...*`, сохраняя
  содержимое и структуру абзаца. Такая замена — **форматная правка**, а не
  литературная или грамматическая: текст внутренней речи не меняется,
  журнал фиксирует её одной строкой (количество случаев).
* Правку `_…_ → *…*` разрешено выполнять автоматически без сверки с JA/EN —
  она не затрагивает содержание.
* Различай две операции. Механическая замена разметки `_текст_` → `*текст*`
  — **форматная** операция: она не касается содержания и не требует
  JA/EN-подтверждения. Классификация абзаца как внутренней речи —
  **смысловое решение**: оно принимается по JA/EN и контексту, и замена
  разметки сама по себе не превращает текст во внутреннюю речь и не
  доказывает её. Не путай форматную замену и смысловую классификацию.

## Курсив (только по функции)

Курсив — для: внутренней речи (см. выше — обязательна всегда); телепатии и речи
на расстоянии; заклинаний,
произнесённых «не вслух» (если так в JA); разовых смысловых ударений
(не чаще 1–2 на главу и только там, где ударение есть в JA/EN);
писем и записок — письма оформляй blockquote `>` + курсив.

## Оформление чужого для текста

* Звукоподражания (JA-звуки в скобках/отдельной строкой) — передавай по-русски
  словом или конструкцией («бахнуло», «звяк»), не латиницей.
* Флэшбеки/вставки — обычным текстом, если нет явной маркировки в JA/EN;
  при явной — весь абзац курсивом.
* Песни/стихи — курсивом, построчно. Переносы строк при этом выполняются
  **внутри одной записи `ED_RU`** (см. «Техническое ограничение» выше): число
  и порядок alignment-абзацев не меняются, отдельное исключение для песен
  не требуется. Решение пользователя 19.09.2026 (ch01 абз. 12): песня —
  6 стиховых строк внутри одной ED_RU-записи.

## Типографика

* Многоточие — символ `…`, не три точки.
* Интервальные тире с пробелами: `слово — слово`. Диапазоны — без пробела.
* Кавычки/скобки/тире не разделяй пробелом от слова внутри.
* Двойные пробелы запрещены. Абзацы разделяются пустой строкой.
* Числа: однозначные и порядковые — словами («две недели», «третий раз»);
  многозначные, даты, время — цифрами. Проценты и денежные единицы — словами
  по контексту.
* Японские гоноративы (-сан/-сама/-кун) по умолчанию не сохраняются — сеттинг
  европейский, следуй EN; титулы — по `dictionary.md`. ИСКЛЮЧЕНИЕ — персонажи
  японского происхождения (см. справочник `addresses.md`): их обращения вида
  «Сайто-сан» сохраняются дословно.

## Порядок слов (инверсии)

* Инверсии сохраняются, если они естественны для художественной прозы и
  поддерживают авторский ритм:
  `Сказал Витторио мягким, но полным достоинства голосом.` — допустимо.
* Неестественные или тяжеловесные инверсии нормализуются до прямого порядка
  слов: `Тихо вымолвила это Луиза.` → `Луиза тихо вымолвила это.`
* Спорное — сначала сверяй с JA: если оборот повторяет построение оригинала
  (особенность стиля автора), оставляй; если это артефакт машинного
  перевода — нормализуй.

## Авторские слова отдельным абзацем после реплики (жёсткий приоритет)

Если авторские слова находятся в **отдельном абзаце после реплики**, они по
умолчанию оформляются как **самостоятельное предложение без тире в начале**.

Сам факт того, что отдельный авторский абзац относится к предыдущей реплике,
**НЕ является основанием добавлять тире**. Тире в начале такого абзаца
запрещено добавлять механически.

Перед изменением необходимо определить функцию абзаца по **JA и EN**:

1. Если JA/EN представляют авторские слова как самостоятельное предложение
   после реплики:

   ```
   — Древняя магия?

   Спросил он, но Саша покачала головой.
   ```

   тире в начале авторского абзаца **НЕ добавляется**.

2. Если JA/EN показывают, что авторские слова являются продолжением той же
   конструкции прямой речи, тире может быть необходимо по правилам прямой
   речи:

   ```
   — Древняя магия? — спросил он.
   ```

3. Нельзя переносить правила оформления **встроенных** авторских слов на
   **отдельный следующий абзац**.

**Абзацное членение источника имеет приоритет** над предположением редактора
о том, что два предложения логически связаны. Если JA и EN оба оформляют
фрагмент как отдельное предложение после реплики, это является достаточным
основанием сохранить отдельный авторский абзац без начального тире, если
русская пунктуация сама по себе не требует иного.

**Запрет на «улучшающую» пунктуацию:** редактор не должен добавлять знак
препинания, которого нет в исходной синтаксической конструкции, только для
усиления интонационной связи между соседними абзацами. Пример цепочки:

```
JA: 尋ねると、サーシャは首を振った。
EN: He asked, but Sasha shook his head. → He asked, but Sasha shook her head.
RU: Спросил он, но Саша покачала головой.        ✔
RU: Спросил он — но Саша покачала головой.         (навязанное интонационное тире)
```

Тире перед `но` в русском возможно как авторский интонационный знак, но это
**необязательная авторская перестройка**: без основания в JA/EN редактор её
не делает.

### Что при этом запрещено менять в обратную сторону

* **Механически удалять тире из абзаца только потому, что он содержит
  глагол речи, запрещено.** Сначала определи функцию абзаца по JA/EN
  (пп. 1–3 выше); тире снимается только если JA/EN показывают
  самостоятельное предложение, а не продолжение конструкции прямой речи.
* **Абзацная структура и соответствие.** Границы абзацев внутри смыслового
  блока — твоё решение по синтаксису и композиции (см. «Абзацное оформление
  прямой речи» выше); неизменна только граница смыслового блока. Слияние
  `— Реплика, — атрибуция.` допустимо, если так строится русская реплика;
  соответствие проверяется по блоку (`check_alignment.py`).
* Абзац-атрибуция, который в JA/EN является продолжением той же конструкции
  прямой речи (`— Обе они примут участие в церемонии в сане монахинь.` /
  `— Пояснила Аньес остолбеневшей публике.`), **сохраняет тире**.
* Образец отдельной атрибуции без тире: `С тревогой пробормотал Маликорн.`
  при JA-абзаце マリコルヌが心配そうに呟く — отдельный JA-абзац-наррация.
* При сомнении — пометка `???` и решение человека, а не авто-правка.
