# Ревизия skills — вторая ревизия по ручной проверке v3-ch01 (round 2)

База: коммит `828e24c` (v3-ch01 manual fix) — ручные правки, не выявленные
текущими проверками после первой ревизии (`skills-revision-v3-ch01.md` +
`-addendum.md`). Задача — не накопить правила, а переработать, объединить
и там, где необходимо, дополнить существующую систему так, чтобы
аналогичные ошибки находились в будущих главах. Новые skills и новые
scanners НЕ создавались.

## 1. Краткое резюме

Случаи ручного фикса сведены к 7 системным классам (A–G). Корневые причины
пропусков — не отсутствие правил, а:

1. **противоречие формулировок** (регистр титулов: russian-prose-rules
   «заглавная только при обращении» ↔ gold standard «почтительная заглавная
   в речи» ↔ hint сканера) — кандидаты находились, но получали неверный
   disposition FALSE POSITIVE;
2. **слишком узкая формулировка существующего правила** (устойчивые
   конструкции JA = только «усилительные»; quotespeech = только абзац
   ЦЕЛИКОМ в кавычках; канон термина = «наличие строки в словаре»);
3. **отсутствующий порядок этапов** (нет гарантии финальной
   терминологической сверки ПОСЛЕ всех правок GRAMMAR/STYLE/FORMAT);
4. **отсутствующие обобщённые классы** (аспект/повторяемость действия,
   semantic scope, оценка vs идентификация, прагматика регистра, общий
   принцип сносок, голос нарратора после реплики) — закрыты ADD;
5. **конфликт внутри словаря** (строка `魔法学院 → «Академия Волшебства»`
   против практики завершённых томов «Магическая Академия») — закрыт
   правилом приоритета источников, НЕ правкой словаря; конфликт вынесен
   на решение пользователя (USER DECISION).
