## 2. Грамматический контроль (russian-grammar-control)

Охват: сплошной — все 17 блоков / 269 абзацев разобраны по схеме

GRAMMAR FINAL AUDIT).

### Кандидаты предфильтра (8/8 разобрано)

1. **б1 «Это был капитан…, сгоревшего… и ушедшего на дно»** — detection:
   RU-пассив «был + причастие». Схема: «Это — капитан X» (выделение), причастия
   активные и относятся к «линкору» = JA 炎上沈没した (действие корабля), EN-окно
   смежено с другим предложением. **disposition: FALSE POSITIVE.**
2. **б1 «В городке… с помпой проводился парад»** — detection:
   EN-пассив ↔ RU возвратный. Схема: подлежащее «парад», глагол
   «проводиться» — страдательного залога (само событие претерпевает
   проведение), JA 行われていた / EN «was being held» — залог совпадает;
   деятель не назван нигде. **disposition: FALSE POSITIVE.**
3. **б4 «Пусть трон останется вакантным»** — detection: EN-пассив ↔ RU
   возвратный. «Остаться» — копула состояния, не возвратный глагол с деятелем;
   EN-окно относится к другому предложению («two weights were lightened» —
   «камни… полегчали», тоже корректный актив по JA 軽くなった).
   **disposition: FALSE POSITIVE.**
4. **б5 «Стоило ей задуматься…»** — detection: EN-пассив ↔ RU возвратный.
   «Стоило + инф.» = «как только» (конструкция времени), залога нет;
   EN-окно смежено. **disposition: FALSE POSITIVE.**
5. **б8 «…лишь получив подарок… он чуть не расплакался»** — detection:
   EN «X's Y was raised» ↔ RU. «Получив» — деепричастие при подлежащем «он»,
   роли не смещены; EN-окно = следующее предложение (120 %).
   **disposition: FALSE POSITIVE.**
6. **б14 «Сиеста, прижавшись к его груди, громко ныла»** — detection:
   EN-пассив ↔ RU возвратный. Деятель — Сиеста, JA シエスタは…才人の胸にすがって
   (активное прижимание); «прижавшись» — деепричастие её же действия.
   **disposition: FALSE POSITIVE.**
7. **б15 «И это был пеликан»** — detection: RU-пассив «был + причастие».
   Выделительное «был» + существительное (JA …それは一匹のペリカンだった);
   агент не требуется, EN-окно смежено. **disposition: FALSE POSITIVE.**
8. **б15 «…осторожно попятился к двери»** — detection: возвратный глагол ↔
   EN-пассив-окно. «Попятиться» — непереходный глагол движения, деятель —
   Сайто; JA 抜け出そうとした (он же) — залог не менялся; способ передан по
   EN «backed towards the door», последовательность действий по JA
   сохранена. **disposition: FALSE POSITIVE** (смысловое наблюдение — §1, б15).
